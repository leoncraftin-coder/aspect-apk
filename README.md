# Растяжка экрана

Android-приложение, которое растягивает весь экран телефона под выбранные пропорции: 16:10, 4:3, 5:4, 3:2, 16:9, 1:1, 2:1, 21:9 или свой формат.

Под капотом используются системные команды `wm size` и `wm density`. Картинка растягивается на весь физический экран, как «растянутое» разрешение в играх.

## Сборка

1. Установите Android Studio (Koala или новее).
2. Откройте папку проекта (`File > Open`). Студия сама скачает Gradle и зависимости.
3. Подключите телефон с включённой отладкой по USB и нажмите Run.

## Выдача разрешения (один раз)

Без разрешения система не даёт менять размер экрана. На компьютере выполните:

```
adb shell pm grant com.aspectstretch android.permission.WRITE_SECURE_SETTINGS
```

Если на телефоне есть root, команда не нужна: приложение запросит root при первом применении формата.

## Как пользоваться

1. Выберите формат или введите свой.
2. Включите «Сохранять размер интерфейса», если не хотите, чтобы кнопки и текст менялись по размеру.
3. Нажмите «Применить». В течение 15 секунд подтвердите «Оставить», иначе прежний формат вернётся сам.
4. «Сбросить к родному формату» возвращает исходный экран.

## Если экран стал неудобным

Выполните на компьютере:

```
adb shell wm size reset
adb shell wm density reset
```

Изменение размера экрана сохраняется после перезагрузки.

## Как считается размер

Если выбранный формат менее вытянут, чем экран, уменьшается длинная сторона. Если более вытянут, уменьшается короткая. Значения округляются до чётных. Пример для экрана 1080x2400:

| Формат | Результат |
|--------|-----------|
| 16:10  | 1080x1728 |
| 4:3    | 1080x1440 |
| 16:9   | 1080x1920 |
| 1:1    | 1080x1080 |
| 21:9   | 1030x2400 |

## Ограничения

- Работает не на всех прошивках: некоторые производители блокируют `wm size` для обычных приложений.
- Для ландшафта ничего менять не нужно: размер задаётся в естественной (портретной) ориентации, игра в горизонтальном режиме получит те же пропорции.
- iOS не поддерживается: система не позволяет менять пропорции экрана.
